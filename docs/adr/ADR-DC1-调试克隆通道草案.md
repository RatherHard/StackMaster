## 一、决策内容(核心条款)

**新增一条独立于会话动作协议的"调试通道":调试 VM 与真实实例由同一公开条件集分别生成,seed 与私有判题包对调试 VM 零装载,会话权威动作日志在调试 VM 上确定性重放以对齐状态;调试侧一切交互不进权威日志、不参与判题与回放。公开投影契约(12 动作、5 命令、投影 7 字段、D3/D5)一字不动。**

条款拆解:

1. **通道独立**:调试协议是独立版本化的新契约(帧面示意:`debug_attach` / `debug_window`(任意地址窗口) / `debug_step` / `debug_run_to_breakpoint` / `debug_search` / 展示流帧;仅示意,冻结面待评审),不复用、不扩展 `ActionObjectSchema` 的封闭枚举;golden fixture 与 Rust(serde + schemars)消费面随新契约建立。

2. **生成条件 = 公开条件集**:调试 VM 与真实实例从同一**公开条件集**分别生成——公开描述包、VM Profile、内存布局(含隐藏区域的几何/权限,几何是公开布局常量)、代码区、初始可见投影。**seed 与私有判题包(`judgingConfig` / 隐藏测试 / 判题编排)对调试实例零装载**:秘密差异是结构性的——调试进程内自始不存在秘密材料,而不是"存在但被过滤"。"零装载"优于"零过滤"优于"过滤":过滤面随状态内容增长且需逐帧论证,零装载把论证收缩为"装载清单里没有"。

3. **哑值填充**:隐藏区域内容、canary 期望等秘密派生槽位以**确定性哑值**填充;区域布局、大小、权限与真实实例同构。同构保证视角导航与 what-if 执行的布局保真(跳转到隐藏区域看到的是哑值,不是"未映射"的谎言);哑值规范(固定常量还是公开包派生)见开放点 2。

4. **状态对齐 = 权威动作日志确定性重放**:调试 VM 把会话权威动作日志(类型 + 参数;动作参数是玩家输入,属公开面)从 revision 0 起确定性重放(可从任一 checkpoint 对应的日志位置起),对齐到当前 revision。**禁止把真实 checkpoint 快照恢复进调试进程**——快照含秘密,恢复即破坏零装载;经秘密置换变换后的恢复列为后续优化,不入首版。调试 VM 自身确定性(固定哑 seed),其重放同样满足 6.3。

5. **调试交互不进权威日志**:调试侧的执行只改调试 VM;append-only 权威动作日志仍只含真实会话动作;verifier 回放面与 `replay_mismatch` 语义零改动。调试侧交互不受判题闸门约束(gate/settle 属判题编排,调试 VM 未装载)——这是 what-if 语义的组成部分,资源面由调试协议自身预算约束(开放点 5)。

6. **判题能力 = 输入缺失,而非功能开关**:调试 worker 没有"关闭判题"的代码分支——它无可判之物。即使调试 worker 实现有缺陷,也不存在可供泄露的判题逻辑输入与秘密期望值。

7. **能力承载面**:任意地址视角/窗口重锚定、全内存字节检索、完整伪指令流(服务端生成的**展示数据**,源 = 公开代码区字节;引擎可执行 IR 仍不出进程,D5 边界在调试通道同样适用)、函数表、地址断点 / run-to-breakpoint、pwndbg 式跳转链全延伸——均由调试通道承载。公开投影维持现状(`currentInstruction` 单条、窗口锚定区域起点)。

8. **what-if 纪律**:秘密依赖分支上的分叉是固有属性(典型:canary 哑值使"泄漏真实 canary 再重建"类技巧只能练流程、不能练取值);"调试通过 ≠ 提交通过"必须由 UI 显式呈现,调试结果不得渲染为权威结论。

9. **与"判状态"语义的衔接**:判题考的是 VM 状态满足由 seed/私有包决定的谓词期望(`ret_target_equals` / `memory_equals` / `stack_canary_intact` / `memory_contains` 等,《判题语义规约》§二)。因此同 seed 的调试视图 = 谓词期望值答案册——选手读出期望值后在真实会话用 `write_bytes` 摆放即可伪造达标。这是条款 2 零装载的直接动因,不是可选优化。

## 二、备选方案与拒绝理由

| 方案 | 结论 | 理由 |
|---|---|---|
| A. 需求降级:视角/检索限定在已下发窗口内 | 公开视图保留此形态 | 不满足源文档的 pwndbg 式体验(M3 的需求本源);作为公开视图档的形态保留,不作为全局答案 |
| B. 推翻/扩写 D3:公开协议加"任意地址读窗口" | 拒绝 | 等于给选手内存读取原语;哪些地址被接受/拒绝、响应长度、时序全要逐一论证不泄露映射布局(9.2),D3 的"服务端一次性组装、无运行时查询面"论证被放弃,成本高且不可逆 |
| C. COW fork 克隆(从当前 revision 复制) | 拒绝 | fork 把真实 canary、派生期望值物理复制进调试进程,秘密随即在进程内存在,零过滤即泄露;退化为"过滤的 fork"则回到方案 B 的论证复杂度。"重生成 + 日志重放"达到同样的状态对齐而不携带秘密 |
| D. 前端本地 VM 执行调试 | 拒绝 | 违反底线 1/3(浏览器无权威执行)与产物隔离纪律(浏览器不得加载 VM Core / 引擎产物);且前端无题目包可载 |
| **E. 调试克隆(本 ADR)** | **选定(草案)** | 真实 pwn 工作流的结构等价物:本地全可见调试 + 远端判题出分;公开协议零改动,秘密面以构造方式闭合 |

## 三、与既有纪律的逐条衔接

| 纪律 | 衔接 |
|---|---|
| 底线 1/2(完整状态隔离在后端;浏览器只收可公开的脱敏投影) | 调试通道数据的"可公开性"由零装载在构造上保证:公开性论证从"policy 过滤正确"扩展为"输入里没有秘密"。底线语义不变,论证方式新增一条结构性路径 |
| ADR-7(脱敏在执行域内完成) | 调试 worker 同为执行域(信任域 3);其"全可见策略"作用于无秘密输入的克隆 |
| D3(窗口锚定区域起点) | 对公开投影**维持冻结**;任意窗口仅存在于调试通道 |
| D5(currentInstruction;"展示数据非可执行 IR") | 公开投影不动;调试通道下发的是服务端生成的伪汇编**展示形态**,引擎 IR 本体不出进程 |
| 6.3(确定性) | 调试 VM 固定哑 seed,同条件同日志重放逐字节可复现;重放对齐依赖的正是既有的确定性纪律 |
| 9.2(侧信道) | 调试通道无秘密,长度/时序差异不构成泄露面;"某题是否启用调试"是产品可见差异,非秘密 |
| 判题面(verifier 复用同一回放引擎,ADR-8;submit 只回引用,D-W8-9) | 调试通道与 verifier/隐藏测试/seed 零交集;"提交判题走新进程重放"本就是既定架构(阶段六 verifier),本 ADR 不改变它 |

## 四、影响面

- **前端需求**(见《前端交互需求拆解.md》§十二):受 M3/M4 约束的条目验收拆为"公开视图档 + 调试视图档"双档;FE-ST-05 / FE-FV-04 / FE-IN-01~07 / FE-IN-08 / FE-WS-04c / FE-PB-02 断点积木等在调试视图档获得数据源与原生断点。FE-PB-04(出题者积木,M10)属公开描述包演进,不在本 ADR 覆盖内。
- **校验清单**:M3/M4/M7 处置方向本次回填;M5/M6/M12 受益,处置方向待下轮回填。
- **契约与机检**:调试协议独立版本 + golden fixture + Rust 消费面;《数据分类与秘密零驻留清单》新增"调试通道"分类行(公开性由零装载保证);ZR 机检扩展——调试通道帧语料对哑化镜像的包含性断言(帧内容 ⊆ 公开条件集派生的克隆状态,复用 ZR-B 系语料扫描思路)。
- **工程与资源**:每个启用调试的会话按需 +1 个 vm-worker 进程;生命周期(attach 时生成、空闲回收)复用 WP-6 断线保持/回收机制;重放对齐的成本 = 重放动作日志长度,MVP 可接受,scrubbed checkpoint 恢复优化留 T2。

## 五、开放点(评审须裁决)

1. **entitlement**:题目启用调试的声明位置——公开描述包字段(如 `debugMode`)还是租户/平台权益?涉及 7.1 字段分类与双包 Schema。
2. **哑值规范**:canary/隐藏区域哑值的生成规则(全局固定常量 vs 公开包派生);哑值是否可被挑战设计反向利用(教学设计面)。
3. **调试协议帧面与传输**:独立 WSS 端点(如 `GET /sessions/debug-channel`,Cookie 凭证同源)还是既有通道扩帧族;帧集冻结面。
4. **UI 形态**:调试视图作为工作区内新标签页(贴合源文档的工作区模型,倾向此项)还是视图内双档切换;what-if 标识的呈现规范。
5. **调试侧资源预算**:调试动作频率/窗口请求频率的限流与预算,与 D-API-50~53 的关系(独立计费 vs 共享)。
6. **重放桥**:"把调试侧录制的动作序列一键应用到真实会话"是否入 MVP(走正常动作链路、受全部校验/限流,实现上是动作重放,无新协议面)。
7. **登记**:接受后在计划书 5.4 的 ADR 编号登记与《前端交互需求拆解.md》源文档增补("调试模式"不是源文档需求,产品侧确认后并入)。
