## 四、双档数据源抽象(评审解耦的关键约束)

```
interface MemoryDataSource {          // UI 组件只依赖此接口
  regions(): VmaList;                 // FE-FV-06
  registers(): RegisterRow[];         // FE-RG-01/02
  bytesRows(range: AddrRange): Row[]; // FE-ST/FE-FV 行渲染
  search(query: ByteQuery): Hit[];
  instructionStream?(range): Instr[]; // 调试档独有;公开档 undefined
}
```
- 公开档 `ProjectionDataSource`:数据源 = 冻结公开投影,语义受 D3(窗口锚定区域起点)与 `currentInstruction` 单条约束——越界查询返回"窗口外"而非报错;
- 调试档 `DebugDataSource`:ADR-DC1 评审后填充,全量语义;`instructionStream` 仅此档存在;
- **纪律**:视图组件禁止绕过接口直读 `session-client` 投影存储——这是"评审结果不影响已写代码"的唯一保证点,评审前由 code review 把关,评审后可升级为 dependency-cruiser / ESLint 规则。
