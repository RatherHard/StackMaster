# 阶段五 WP-53 决策草稿(主题与语言机制面,vm-ui 增量)

> 状态:实现期草稿(2026-09-11,WP-53 交付时成文)。**本文不是权威决策记录**:正式 D-API 增补与文档回填由 WP-56 统一收尾;本文供 WP-55(E2E 与 13.4 矩阵、axe 真机补测)消费对接接口,并作为 WP-56 回填的事实来源。

## 一、Q6 定案:主题层最小面(双主题 + auto;功能对比度,零视觉重设计)

1. **变量面 = 8 个 CSS 自定义属性**(`src/theme/theme-tokens.ts`),light 值 = 现行硬编码值**原样**(light 下像素级零变化,既有单测与独立使用形态不破),dark 值 = 功能对比度初值(白透明等可见度放大 + danger 提亮):

   | 变量 | light(= 现行值) | dark(初值) | 现行覆盖对象 |
   |---|---|---|---|
   | `--sm-border` | `rgb(0 0 0 / 15%)` | `rgb(255 255 255 / 22%)` | 卡片 / 画布 / 输入边框 |
   | `--sm-border-button` | `rgb(0 0 0 / 20%)` | `rgb(255 255 255 / 30%)` | 按钮边框 |
   | `--sm-border-strong` | `rgb(0 0 0 / 25%)` | `rgb(255 255 255 / 40%)` | hover / 强调边框、按钮边框(checkpoints) |
   | `--sm-divider` | `rgb(0 0 0 / 10%)` | `rgb(255 255 255 / 14%)` | 行分隔 / 工具栏分隔 |
   | `--sm-divider-faint` | `rgb(0 0 0 / 8%)` | `rgb(255 255 255 / 10%)` | 表行分隔 |
   | `--sm-badge-bg` | `rgb(0 0 0 / 8%)` | `rgb(255 255 255 / 14%)` | 徽标底(kind / 徽章) |
   | `--sm-badge-bg-soft` | `rgb(0 0 0 / 4%)` | `rgb(255 255 255 / 8%)` | 弱徽标底(timeline status) |
   | `--sm-danger` | `crimson` | `#ff8a94` | 编译错误 / 断点红 / 错误日志 |

   dark 数值为**功能对比度初值**,以 axe 真机门禁为唯一口径(边界裁决 2),WP-55 真机报告按需修正。

2. **系统颜色关键词不入变量面**:组件既有样式的 `canvas / canvastext / graytext / highlight / accentcolor / mark / field / linktext` 及其 `color-mix` 组合随 `color-scheme` 自动适应明暗(嵌入形态由 WP-52 落内联 `color-scheme`),无需变量化——这是"最小面"能收敛到 8 个的原因。

3. **注入机制(自定并登记)**:变量经 **`data-sm-theme` 属性锚 + 文档级样式表 + CSS 自定义属性继承**落地——`ensureSmThemeStyles()` 向宿主文档幂等注入一份 `<style id="sm-theme-token-styles">`(jsdom 无 constructable stylesheet,故用 style 元素;各组件 `connectedCallback` 幂等调用)。文档级规则命中携带锚的宿主元素(嵌入形态 = `<pwn-memory-vm data-sm-theme="…">`,WP-52 已落锚),自定义属性沿 composed 树继承穿透各级 shadow DOM,vm-ui 全部组件在自身 shadow 内以 `var(--sm-*, <light 值>)` 消费——嵌套组件零重复定义、组件零硬编码颜色(机械护栏测试断言:var() 之外无 `rgb(0 0 0` / `crimson`)。

4. **auto 的系统跟随由 CSS 承担,vm-ui 零 JS 解析**:锚三值 `light|dark|auto` 全支持;`auto` 的暗色规则置于 `@media (prefers-color-scheme: dark)` 内,无 matchMedia 订阅、无监听器泄漏。**边界登记**:嵌入形态的 `auto` 已由 WP-52 `EmbedAppearanceController` 按插件自身 `prefers-color-scheme` 解析为二值 `resolvedTheme` 落 `data-sm-theme`(matchMedia mock 测试在 web-component 侧 `test/plugin/appearance.test.ts`),两条 auto 路径互不依赖;vm-ui 的 CSS auto 路径服务独立使用形态(以及未来直接以三值锚接入的宿主)。

5. **独立使用形态**:`<sm-workspace theme="light|dark|auto">` 属性把值转写为自身 `data-sm-theme`(最近锚优先——显式属性胜过祖先锚,确定性;归位 `null` 只清理自身写入面)。

6. **axe 双主题**:`test/theming/theme.test.ts` 对 ED 七组件满内容形态在 light / dark 锚下各跑一遍 axe,零 violations(`color-contrast` 沿既有豁免登记:jsdom 无布局引擎,任何对比度结论都是环境伪影;真机补测归 WP-55)。

## 二、Q5 定案:语言内置集与 i18n 抽取面

1. **MVP 语言集 = {zh-CN(默认), en}**:默认语言 = 现行文案语言;**zh-CN 目录值 = 现行文案原样**(抽取是"键化"不是改写)——既有 518 用例的文案断言一字不差全绿,这是"抽取面只增不破"的落地形式。`en` 目录给出真实可读英文翻译(非逐字机翻)。
2. **抽取面 = 全量用户可见字符串**(~420 键):工作区菜单 / 断线重连横幅 / what-if 横幅 / 拒绝错误呈现、工作区空态与调试状态行、四视图(字节 / VMA / 寄存器 / 指令 / 跳转链)全部空态 / 占位 / 明示文案与 aria-label / placeholder / title、ED 七组件、payload 三区与执行日志、编译器错误与步骤标签(呈现于程序区 / 输出区 / 警示气泡)、时间线摘要、tab 注册表展示名、积木文案 / 工具箱分类 / tooltip(FE-PB-06)。
3. **不入目录的"用户可见但属数据"面**:协议 / 状态机词原样呈现(连接态 `connected/reconnecting/…`、投影 status、执行器状态、动作类型名 `write_bytes/…`、"revision" 词);数据值(地址、regionId、寄存器名、checkpointId、错误 code、字节十六进制)。这些是协议词汇不是 UI 文案,翻译它们反而破坏与契约的同形性。
4. **目录结构**:zh-CN 目录为键集事实源(`as const` → `SmMessageKey`),en 目录 `Record<SmMessageKey, string>` 类型强制同键集(缺键 / 多键 = 编译错误 + 完整性测试红灯);参数占位 `{name}` 双语同构(测试断言占位符集合一致)。键命名 `<域>.<语义名>`(menu / workspace / byte / vma / reg / annot / instr / chain / ed / payload / compile / timeline / block / debug / tab / common)。
5. **BCP-47 匹配降级确定性**(`resolveLocale`):精确匹配(大小写 / 下划线归一)→ 主子标签前缀匹配(zh-TW → zh-CN、en-GB → en)→ 内置默认(zh-CN);未知 / 空 / 非法标签确定性落默认(协议 Schema 已在 web-component 侧拒非法语法,本层为最后兜底)。测试含全矩阵。
6. **响应式 locale**:模块级单例 store(`setLocale / getLocale / onLocaleChange`,与 `EmbedAppearanceController` 同词汇)+ Lit `LocaleController` 组件订阅(连接时消费锚 + 变化即重渲染)。**全局单 locale 属 MVP 形态定案**(iframe 内单工作区;独立多实例多语言留演进)。
7. **锚消费**:`consumeAnchoredLanguage()` 沿 composed 树(父链 + shadow host 链)找最近 `[data-sm-language]` 解析应用,并对锚挂共享 MutationObserver——运行中 `language_changed` 更新锚属性即生效。**时序契约**:WP-52 宿主元素在自身 `connectedCallback` 即落锚(早于工作区挂载),组件消费点(连接时刻)锚已在场;锚晚于组件连接出现不追溯(登记,嵌入形态不发生)。
8. **固化语义(定态登记)**:状态字符串(payload 执行日志、跳转 / 检索状态行、时间线 / 编译步骤标签)按**生成时刻 locale** 固化;语言切换重渲染刷新模板内 t() 求值面。标签页标题在打开时刻求值(经 `descriptor.labelKey` 解析)。积木画布文案按 **Blockly 注册时刻** locale 固化(`registerPayloadBlocks()` 经 `buildPayloadBlockDefinitions()` 取词;`PAYLOAD_BLOCK_DEFINITIONS` / `PAYLOAD_TOOLBOX_CATEGORIES` 常量保持 zh-CN 快照 = 既有测试与公开 API 面不变)。

## 三、遗留登记(WP-55 / 演进项)

1. **积木画布运行中语言切换不追溯**:Blockly 积木定义为注册期固化机制,运行中切换需 dispose + 重注入画布并处理 FE-WS-07 的 payload 状态跨模式保留语义——成本高、收益低(payload 画布术语高度专业化),MVP 以"创建时刻 locale"语义交付;演进项 = Blockly locale 机制接线。
2. **axe color-contrast 真机补测与 dark 变量数值校准**:dark 值为功能对比度初值,WP-55 13.4 矩阵(含主题切换)以真机报告为准修正(边界裁决 2:axe 真机门禁为唯一口径)。
3. **真机 E2E 主题 / 语言切换断言移交 WP-55**(其 13.4 矩阵本含主题切换);对接接口见 §四,本波次不强制跑真实浏览器。
4. **多工作区多语言**:全局单 locale;若未来单文档多工作区多语言,需把 store 升级为按子树作用域(接口面已预留:目录与 t() 纯函数无状态耦合,仅 store 为单例)。
5. **jsdom 无法断言变量级联结果**:变量真实生效(计算样式)的真机验证归 WP-55;jsdom 层以结构断言(样式表规则 / 锚转写 / 机械护栏)代替。

## 四、移交 WP-55 的接口面(E2E 如何切主题 / 语言)

**嵌入形态(宿主模拟页拓扑,WP-52 冒烟复用)**:
- 主题切换:`page.getByTestId("host-mock-theme-select").selectOption("dark")` → 宿主经 embed-runtime `EmbedSession.sendThemeChanged("dark")` 发 `theme_changed` → 断言 `iframe` 内 `pwn-memory-vm[data-sm-theme='dark']`(WP-52 冒烟第六步既有)→ **WP-53 增量断言**:iframe 文档存在 `<style id="sm-theme-token-styles">` 且其内含 `[data-sm-theme="dark"]{--sm-border:rgb(255 255 255 / 22%)…}`;`getComputedStyle(pwn-memory-vm).getPropertyValue("--sm-border")` 命中 dark 值(真机级联可判定);
- 语言切换:宿主 `page.getByTestId("host-mock-language-select")` → `EmbedSession.sendLanguageChanged("en")` → 断言 `pwn-memory-vm[data-sm-language='en']` + 工作区菜单按钮文本变为英文(`menu.step` = "Instruction step";zh-CN↔en 双向);未知标签("fr")断言回退 zh-CN(确定性);
- 未授予降级(§4.4):`grantedCapabilities` 不含 theme / language 的矩阵行 → 断言 `data-sm-theme` 恒 "light"、`data-sm-language` 恒 "zh-CN",且菜单文案恒中文(jsdom 侧等价锚 = `test/i18n/locale-anchor.test.ts` 无锚组 + `test/theming/theme.test.ts` 无锚组,与 web-component `test/pwn-memory-vm.test.ts` 能力降级矩阵组共用语义)。

**独立形态(不开 iframe 的轻量断言路径)**:
- `<sm-workspace theme="dark">` 属性(转写为宿主自身 `data-sm-theme`);或任意祖先元素 `data-sm-theme` / `data-sm-language`;
- 组件外 API:`setLocale("en")`(经 `onLocaleChange` 全组件重渲染)、`ensureSmThemeStyles(document)`(幂等)。
