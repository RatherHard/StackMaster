## 二、十五章 13 项观察项(逐项:数据来源 / 判据 / v1 可得性)

> 阅读口径:每项 = 「**数据来源**」类属与具体出处 → 「**判据**」(达到什么算好 / 算需干预)→ 「**v1 可得性**」→ 「**填报值**」(留空,试用后填)。判据中的**数值阈值一律在首轮基线产出后定**,本模板不预设任何未经验证的数字(计划书第十五章:「而不是把尚未验证的数字写成既定承诺」)。

### 2.1 首次成功时间(打开题目 → 首次成功)

- **数据来源**:受控查询。`sessions`(`created_at`、`challenge_id`、`challenge_version`、`tenant_id`)× `submissions`(`session_id` → `id`)× `verdicts`(`submission_id` → `verdict`、`created_at`);取每会话**首个 `verdict = success` 的时刻 − 该会话 `sessions.created_at`**。聚合输出仅按题目 / 版本分组的**分位数与计数**,不含会话 ID / 用户标识。
- **判据**:算好 = 各题首成功时延的中位数与 p90 落在教学规模可接受区间(阈值首轮基线后定),且未成功会话占比低;算需干预 = 某题大量会话始终无首成功,或长尾(p90 显著高于中位)集中。
- **v1 可得性**:**v1 可采集**(服务端可派生三类之一「通过」+「题目开始」——O-MP-1 定案;实现路径 = 受控查询,`teaching_events` 落地后可改由该表承载同一口径)。
- **填报值**:待补取证。

### 2.2 完成率与放弃率

- **数据来源**:受控查询。`sessions`(`challenge_id` 分组 × `phase ∈ {active, crashed, closed}`)× `verdicts`(11 值裁决方向);完成 = 该会话存在 `success` 裁决;放弃代理 = 终态会话(`closed` / `crashed`)且无 `success` 裁决。输出按题目分组的**比率 + 计数**。
- **判据**:算好 = 栈序列(CH-01~06)完成率显著高于放弃率,梯度有序(后题不出现断崖);算需干预 = 某题放弃率显著高于同组、或梯度出现断点(教学路径断裂,计划书 14 章「题目质量不一致」风险行)。
- **v1 可得性**:**v1 可采集**(受控查询)。
- **填报值**:待补取证。

### 2.3 提示使用等级与回退次数

- **数据来源**:
  - **回退次数 = 受控查询**:`action_log` 中动作类型为 `undo` 的行(`action` 列是规范化动作对象 JSONB,动作类型判别字段 = `type`,取值域 = 12 冻结动作类型;`undo` 为其一)→ 按会话 / 题目分组的计数;交叉校验面 = **已有指标族** `session_api_action_rtt_seconds_count{action="undo"}`(全局动作计数;标签零标识符 ⇒ **不可**按学习者 / 题目分组,只作总量校验)。
  - **提示使用等级 = 人工访谈**(v1 兜底):服务端无记录入口。
- **判据**:算好 = 各题提示使用等级分布整体偏低且回退次数随题目难度**有序上升**(说明学习者在试错而非乱试);算需干预 = 高等级提示(接近直接给答案)占比过高,或回退次数在入门题即异常高(入口门槛过高)。
- **v1 可得性**:
  - 回退次数 = **v1 可采集**(受控查询;O-MP-1 三类之一);
  - **提示使用等级 = v1 暂不可采集** —— 原因:`hintLadder` 只存在于**公开描述包**,服务端**无记录入口**(服务端无 hint 使用记录面);**不得靠客户端自报、不得伪造计数**(O-MP-1 定案原文口径)。兜底 = 人工抽样(试用期访谈 + 观察);触发条件 = 采集面扩展(additive 上报契约或服务端记录入口,归后续工作包)。
- **填报值**:回退次数 = 待补取证;提示使用等级 = **v1 暂不可采集**(以访谈结果单列)。

### 2.4 错误类型分布及重复错误比例

- **数据来源**:
  - **裁决方向分布 = 受控查询**:`verdicts.verdict`(11 值冻结枚举)按题目 / 版本分组计数;桥接 `submissions`(`session_id` → `id`)。
  - **动作结果类总量 = 已有指标族**:`session_api_action_rtt_seconds_count{action, outcome}`,其中 `outcome ∈ {accepted, rejected, error}`(有界三值),`action` ∈ 12 冻结动作类型 + `other`;给出「按动作类型的拒绝 / 异常总量」。
  - **重复错误率**:需按同一学习者 / 同一会话的**错误序列**统计,无 v1 采集面(见 v1 可得性)。
- **判据**:算好 = 错误分布集中在少数可解释类型(端序 / 槽位 / 长度),重复错误比例随题目推进下降(学习曲线成形);算需干预 = 同类错误在后续题目中高频重复(模型未迁移),或错误集中于服务端异常类(`error`)而非教学类。
- **v1 可得性**:
  - 裁决方向分布 = **v1 可采集**(受控查询);
  - 动作拒绝 / 异常总量 = **v1 可采集**(已有指标族);
  - **动作级错误码分类(16 错误码)分布 = v1 暂不可采集** —— 原因:**被拒动作不入 `action_log`**(落库纪律:仅已接受动作入账,D-W8-9 同源)⇒ 库内无动作级错误分类面;指标族只给有界三值的总量,不给 `wrong_answer` / `invalid_action` / `memory_fault` 等分类;
  - **重复错误比例 = v1 暂不可采集** —— 原因:需要按会话聚合的错误序列,既有采集面不具备;兜底 = 人工抽样。
  - 触发条件 = 采集面扩展(应用事件 / 分类计数族),归后续工作包。
- **填报值**:裁决方向 = 待补取证;动作拒绝 / 异常总量 = 待补取证;错误码分类与重复错误率 = **v1 暂不可采集**。

### 2.5 学习前后对地址、栈帧、端序和控制流的概念理解变化

- **数据来源**:**人工访谈**(前测 / 后测问卷;服务端零采集面,不得由会话行为反推概念理解)。
- **判据**:算好 = 前后测在四个概念维度(地址 / 栈帧 / 端序 / 控制流)出现可解释提升,且提升与题目完成轨迹一致;算需干预 = 完成率上升但概念测无变化(操作记忆而非理解),或端序 / 控制流维度显著滞后。
- **v1 可得性**:**人工抽样**(问卷;不与任何服务端采集面耦合)。
- **填报值**:待补取证(人工)。

### 2.6 动作请求 p50 / p95 延迟与断线恢复成功率

- **数据来源**:
  - **动作 p50 / p95 = 已有指标族**:`session_api_action_rtt_seconds`(histogram;桶 `ACTION_RTT_BUCKETS`,分位由桶计算;标签 `action` × `outcome`)。
  - **断线恢复成功率**:v1 无采集面(见下);兜底 = 人工抽样。
- **判据**:算好 = p50 / p95 在教学规模内稳定且 p95 不随时段恶化(与并发预算配合);断线恢复成功率接近全恢复(重连后经 `sync_projection` 对齐,不降级为本地执行)。算需干预 = p95 长尾化、或恢复失败伴随会话状态不一致反馈。
- **v1 可得性**:
  - 动作 p50 / p95 = **v1 可采集**(已有指标族);
  - **断线恢复成功率 = v1 暂不可采集** —— 原因:`/metrics` 九个族中**无重连 / 恢复计数族**;重连路径(`sync_projection`,受凭证保护)不落库、无计数面 ⇒ 无法计算比率。兜底 = 人工抽样(试用期现场观察 + 访谈)。触发条件 = 采集面扩展(新增重连 / 恢复计数族或应用事件)。
- **填报值**:动作 p50 / p95 = 待补取证;断线恢复率 = **v1 暂不可采集**。

### 2.7 单会话服务端执行延迟与并发会话数

- **v1 可得性**:**v1 可采集**(已有指标族)。
- **填报值**:待补取证。

### 2.13 服务端裁决失败、协议错误和题目配置错误数量

- **数据来源**:
  - **裁决失败 = 已有指标族**:`verifier_runs_total{outcome}`(`outcome ∈ {completed, failed}`)、`verifier_verdicts_total{verdict}`(11 值);伴生 `verifier_queue_depth`、`verifier_verify_duration_seconds`(裁决时延)。受控查询佐证:`verifier_runs.status`、`verdicts.verdict`。
  - **协议错误 = 已有指标族(部分)**:动作面异常总量 `session_api_action_rtt_seconds_count{outcome="error"}`;调试面 `session_api_debug_frames_total{frame, outcome}`(5 值请求帧 + `other`)、`session_api_debug_budget_rejections_total`。
  - **题目配置错误 = 受控查询**:`verdicts.verdict = challenge_invalid` 方向计数(桥接 `submissions` → `sessions.challenge_id` / `challenge_version`);登记管线红灯属 CI 面,不计入试用期数字。
- **判据**:算好 = 裁决失败(`failed`)与题目配置错误(`challenge_invalid`)近零;协议错误类为可解释的少数;算需干预 = 存在非零的 `failed` 集中、或 `challenge_invalid` 出现(题目配置缺陷进试用面)。
- **v1 可得性**:
  - 裁决失败 / 裁决方向 = **v1 可采集**(已有指标族 + 受控查询);
  - 题目配置错误 = **v1 可采集**(受控查询);
  - **协议错误分类计数 = v1 暂不可采集** —— 原因:WSS 错误帧与 16 错误码**无分类计数族**,库内亦无落点(见 2.4);当前只能取动作面 `outcome=error` 总量与调试帧计数的有界枚举。兜底 = 受控日志人工判读(**单列,不进指标面**)。
- **填报值**:裁决失败 / 裁决方向 = 待补取证;题目配置错误 = 待补取证;协议错误分类 = **v1 暂不可采集**。

## 五、隐私与合规自查(随报告同批勾选)

- [ ] **采集面不含学习者标识**:`/metrics` 标签只用有界枚举(12 冻结动作类型 + `other`;`outcome ∈ {accepted, rejected, error}`;调试帧 5 值 + `other`);**会话 ID / 用户 / 租户 / 题目标识不入标签**(Prometheus 基数防护与关联面纪律,D-API-71);受控查询输出的只有**聚合数值 + 有界枚举**;
- [ ] **机检在位**:`assertMetricsTextDiscipline` 对 `/metrics` 输出逐行机检(越名 / 越标签 / 秘密语料 / 服务端签发标识符形态值四类违例),零违例为试用期抓取前提(`apps/session-api/src/metrics/metrics.ts`);
- [ ] **不得经 `/metrics` 通道承载教学事件**:教学事件(题目开始 / 通过 / 回退次数)走**服务端应用事件存储**(`teaching_events` 载体,O-MP-1),不经指标通道(中期计划 §3.4 原文口径);
- [ ] **提示使用 v1 如实登记「暂不可采集」**,不靠客户端自报、不伪造计数(O-MP-1);
- [ ] **试点告知与数据用途说明已就位**:向试点渠道明示「收集哪些数据(聚合指标 + 教学事件)、用途(评估 MVP 教学效果与是否进入高级能力扩展)、不含个人标识、保留期」;告知文本随试用启动与渠道确认(模板本身在渠道确认时定稿);
- [ ] **数据用途边界**:十五章指标用于**验证「提升新生水平与兴趣」的目标并决定是否进入高级能力扩展**,不是把未验证数字写成既定承诺(`docs/项目计划书.md:1033`);
- [ ] **保留期与清除**:快照 / 终态会话 / 审计在线保留窗口按部署配置执行;教学事件保留期随 `teaching_events` 落地定案(O-MP-1 载体含保留期);

## 六、填报纪律与「待补取证」用法

1. **数字零编造**:任何数字必须带**来源**(指标族名 / 受控查询的表 / 访谈记录编号)与**时间窗**;不能核实的写「**待补取证**」并注明核实路径;
2. **不得沿用 dev 拓扑数字**:k6 基线归档(容器首采 `apps/session-api/k6/results/2026-09-09T223628898Z/summary.md`、host 双采 `2026-09-12T130117550Z` / `2026-09-12T134452996Z`,数字与出处见 `docs/phases/阶段六扩展评估报告.md:32-34`)是 **dev / CI 拓扑**的固定锚点,**不得**作为试用环境数字填入;
3. **不得跨通道搬迁数据**:教学事件不得由 `/metrics` 承载;指标不得承载标识符;访谈结论不得伪装成采集数据;
4. **暂不可采集项单列**:见 §2.14 汇总的 4 处,写「暂不可采集 + 原因 + 触发条件 + 归属」,不得静默省略,也不得以代理指标顶替;
5. **阻塞如实登记**:公网可访问(O-MP-5)等前置未解除时,报告状态 = 未启动 + 阻塞原因,**不得写「已达成」**;
6. **报告归档位置**:`docs/phases/`(与本文同目录),文件名建议 `首轮试用报告.md`;原始数据(指标抓取快照 / 查询输出)归档到独立目录并在报告元信息中给出路径,报告正文只放聚合值。
