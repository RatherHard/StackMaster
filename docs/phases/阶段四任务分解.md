# 阶段四任务分解:实现教学 UI

本文件是计划书第十二章"阶段四"的执行层拆解,与计划书冲突时以计划书为准。上游依据还包括:`ADR-DC1 调试克隆通道`(2026-09-10 已接受,调试模式为已评审接受的阶段四范围扩展)、`docs/develop/前端交互需求拆解.md`(FE 需求集)、`docs/develop/前端需求现状校验与不匹配清单.md`(M1~M14 缺口与处置)、`docs/develop/前端实施计划.md`(WP-F1~F7,自本分解生效起由阶段四承接)、`docs/develop/权威API语义规约.md`、`docs/develop/投影语义规约.md`、`docs/contracts/数据分类与秘密零驻留清单.md`。

## 一、阶段定位

**目标**(计划书 §十二阶段四原文):完成公开投影渲染、结构视图、字节视图、寄存器、调用栈、Payload 构造器、diff、时间线、checkpoint、提示和错误解释,并验证键盘操作与基础无障碍体验。

**边界裁决**:

1. **计划书阶段四范围 ⊃ 设计文档需求集**。设计文档覆盖工作区/内存四视图/payload 搭建(FE-XX 46 条);计划书另含结构视图、调用栈、diff、时间线、checkpoint、提示、错误解释、键盘与无障碍——本分解以计划书为完整范围,设计文档未覆盖项以 **FE-ED 系编号**在本分解 §二(WP-F9)直接登记(来源 = 计划书阶段四原文),验收评审前回填拆解文档。
2. **ADR-DC1 扩展**(已评审接受):调试通道(轨道 B)、调试模式档(WP-F8)、工作区解题/调试模式切换(FE-WS-06/07)不在计划书阶段四原文内,登记为本阶段范围扩展,理由 = M3/M4/M7 定案的 pwndbg 式调试体验。
3. **与阶段五边界**:iframe/postMessage/`embed-runtime`/`web-component`/`react-wrapper` 实现、embed token 浏览器面、自适应高度/主题/语言、**公开描述包正式下发通道(M2)** 全部归阶段五;本阶段开发与测试用夹具样例包注入(公开 Schema 校验通过)。`packages/web-component` 本阶段仅建包占位零实现。
4. **与阶段六边界**:verifier、隐藏测试裁决、正式裁决结果展示(submit 响应仅 `{submissionId, revision}`,本阶段只呈现"已提交"态)、审计归档、全面租户隔离,归阶段六。
5. **产出物性质**:`packages/vm-ui`(投影渲染 + session-client)、`apps/plugin-dev`(开发壳)、调试通道与变体镜像的后端/契约面(WP-40~44)、测试与证据。消费已冻结契约,**唯一新增契约面 = 调试通道协议(WP-40 契约先行)**。

**硬门槛(实现期逐条自查)**:

> 浏览器任何位置只保存公开投影与 UI 状态;调试模式档只消费调试通道数据(其公开性由零装载保证,ADR-DC1 条款 2),不得旁路拉取真实私有包内容。
>
> 断线只展示最近一次收到的公开投影,重连走 `sync-projection`;禁止任何形式的本地 VM 执行降级。
>
> 浏览器产物不含引擎代码、私有题目包内容、vm-worker 二进制(`scan:public` 强制);动画只用 compositor 友好属性;字节视图语义化 DOM + 虚拟列表;屏幕阅读器信息不得只存在 Canvas 中。

**已冻结、本阶段直接消费的契约**(不得绕开重造):12 动作 / `ActionResponse` / 16 错误码 / 11 结果类型、5 会话命令与响应、`WssFrame` 三帧族与连接级版本锚定、会话凭证 Cookie 交付(D-API-12)、`PublicStateProjection` 七字段与初始投影、`semanticHighlights` / `callStackSummary` / `PublicHint` / `PublicErrorMapping`(公开描述包面)、限流 429 冻结形态(D-API-50~53)、`sync-projection`;调试通道协议由 WP-40 新冻结。

**工作包编号约定**:轨道 A 沿用《前端实施计划》WP-F 系列;轨道 B 新增 WP-40~44(取"阶段四"义,与阶段三 WP-0~8 无继承关系);轨道 C 复用 WP-F8/F9。
