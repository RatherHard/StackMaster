R1 · 公开描述包字段表（顶层 17 项：13 必填 + 4 可选）

字段类型与约束语义
schemaVersion 必填const 1双包格式信封版本
challengeId 必填^[a-z0-9][a-z0-9-]{1,62}[a-z0-9]$题目公开标识，与私有包同值
challengeContentVersion 必填semver内容版本；与私有包同值
vmProfileVersion 必填semverVM 元数据版本；与私有包同值
locale 必填enum "zh-CN"语言（v1 单值）
briefing 必填{title 1–128, summary 1–2048, learningObjectives 1–8×≤256, teachingNotes ≤8×≤512}题面；全字段禁 C0/C1 控制字符
vmProfile 必填见下虚拟机画像
memoryLayout 必填regions[] 1–64可见布局（区域项见下）
allowedActions 必填≤12 项 unique，12 动作枚举子集选手操作面（附录见学习者指南）
resourceLimits 必填三键全可选：predicateEval 1–1e6 / rollback 1–1e4 / maxWriteBytes 1–4096会话级预算
hintLadder 必填0–8 × {order 1–8 唯一, revealPolicy: on_request|after_n_failures, failureThreshold? 1–1e4, hintText 1–512}提示阶梯；after_n_failures ⇒ threshold 必填
publicErrorMapping 必填0–16 × {errorCode: 16 值枚举, teachingNote 1–512}错误教学注解
initialProjection 必填visibleRegions[]（与布局双射，bytesHex ≤512 hex 字符，truncated 必填）/ visibleRegisters[]（值大写 ^0x[0-9A-F]{1,16}$）/ semanticHighlights? 0–32 × {kind: buffer_start|return_address_slot|saved_rbp_slot|canary_slot|custom, targetRegionId, startAddressHex, byteLength, label}第一屏镜像
randomizationNotice 可选1–200 字符只声明随机化存在；aslrEnabled=true 时必填
debugMode 可选boolean（缺省 true）调试能力开关（opt-out）
aslrEnabled 可选boolean（缺省 false）ASLR 开关；true ⇒ 布局为相对描述 + 必须带 notice
authorBlocks 可选 M101–16 × {id ^[a-z][a-z0-9-]{0,62}$ 唯一, displayText 1–128, interfaceId 256–65535, slots 0–4 × {key ^[a-z][a-z0-9_]{0,31}$ 唯一, label 1–64, kind: address|immediate|length}, actions 1–8 × {type: 12 公开动作, args: 参数名封闭为该动作冻结参数名，值 = 字面量 ≤64 或 {slot: 本模板槽键}}}出题者积木声明面（学员拖积木 → 展开为公开动作序列）；不进 required，不声明则行为与 M10 前一致
vmProfile / regions 嵌套约束
vmProfile.registers[]1–64 × {name: ^(?!FLAG)[A-Z][A-Z0-9_]{0,15}$, displayLabel?}；必含 RSP/RBP/RIP
vmProfile.flagRegisterNames[]1–32 × ^FLAG[A-Z0-9_]*$；只公开名字
vmProfile.archBitsenum 32 | 64
vmProfile.endiannessconst "little"
vmProfile.pageSizeBytes4096–65536，4096 倍数
vmProfile.canary{enabled: boolean, sizeBytes? 1–8}；enabled=true ⇒ sizeBytes 必填（交互题请 false，见 B4）
vmProfile.encodingTable[]1–64 × {tokenHex: ^0x[0-9a-fA-F]{2}$ 唯一, op: 20 opcode ∪ 大写助记符, operands? ≤4 形态声明}；存在即字节模式
memoryLayout.regions[]{regionId: ^[a-z][a-z0-9-]{0,62}$, kind: code|global|stack|heap|key|custom, startAddressHex: ^0x[0-9a-fA-F]{1,16}$, byteLength: 4096 倍数 1–16MiB, permissions: ^r?w?x?$, publicLabel 1–128}；code ≤1 且公开；合计 ≤64MiB

R2 · 私有判题包字段表（13 必填 + 条件/可选）

字段类型与约束语义
身份四字段同公开包，逐项同值XS-ID-CORR
dslSchemaVersion 必填const 2DSL 词汇版本
vmEngineVersion 必填semver锁定执行引擎（照抄语料先例值）
engineBuildId 可选^[A-Za-z0-9][A-Za-z0-9._-]{0,127}$构建 ID（判题记录项）
declaredSeedPublicPaths 必填0–32 项；段.段（≤8 段，段 ^[A-Za-z][A-Za-z0-9_]{0,31}$）种子影响面声明；空 = 无公开随机化面
seedPolicy 必填{strategy: fixed|server_random_per_session, seedHex? 16–64 hex}；fixed⇒必填 / random⇒禁止种子策略（互斥双闸）
initialState.registers 必填≤256 键；键 = 一般名或 FLAG 名；值 ^0x[0-9a-fA-F]{1,16}$ 落 archBits 域完整初始寄存器（含 FLAG 值）
initialState.memoryRegions[] 必填1–64 × {regionId, kind, startAddressHex, byteLength, permissions, contentHex, isHidden}；contentHex 长 = 2×byteLength全部区域（含隐藏）；非隐藏与公开双射
secretSinkRegisters[] 可选1–256 项 unique补充秘密汇声明（只收紧）
secrets 必填{flag 8–128 字符, virtualFiles? 0–8 × {fileId, content ≤4096}}秘密集合
privateObjects[] 必填0–64 × {objectId, kind: buffer|canary|saved_rbp|return_address|file|other, addressHex, byteLength 1–16MiB, visibility: public|hidden, containsSecret}语义登记；secret⇒hidden
judging 必填{successCondition: L1 必填, failureConditions? 0–8×L1, hiddenTests? 0–16 × {testId, kind: predicate_probe|reference_payload, payloadHex? ≤4096B, expectedResult: 7 值}}判题面（见 E2/E3）
judgingConfig 必填{verdictRuleVersion semver 必填, maxPredicateEvalSteps 1–1e7 必填, timeoutMsPerAction? 1–6e4, maxTotalActionBytes? 1–1MiB}判题配置
stages[] 可选0–8 × 六要素（stageId / allowedActions ⊆ 题目面 / preconditions L1 / transitions ≤8 / sideEffects ≤8（v1 仅 grant_virtual_file）/ failureConditions ≤8 / resourceBudget{maxInstructionSteps 必填 1–1e7, maxActions?}）状态机（F1）
compiledIr 条件{irFormatVersion: 2, entrypointIndex?, instructions 1–4096, labels 0–512}；op 双形态；操作数 4 kindIR 模式程序（字节模式省略）
entrypointAddressHex 条件hex 地址，须落代码区字节模式入口（IR 模式不得出现）
customInstructions[] 可选0–16 × {mnemonic ^[A-Z][A-Z0-9_]{0,15}$, displayText 1–120, semantics 1–16 微算子}自定义指令（D4）
interfaces[] 可选0–16 × {interfaceId 0x0100–0xFFFF, displayText 1–120, effects 1–16 效果原语}作者接口（D5）；公开包 authorBlocks[].interfaceId 只能引用这里声明过的接口号（XS-BLOCK-IFACE-REF）

R3 · 基线指令集（20 opcode，封闭）

opcode操作数形态语义摘要标志
movR,I / R,R / R,M / M,R架构值传送（按 archBits 掩蔽）—
push / popR,I —— / R压栈（RSP−=8 后写）/ 出栈（RSP+=8）—
leave—RSP←RBP 后 pop RBP；要求初始集含 RBP；弹出值不可执行时报 invalid_rip—
add / sub / cmpR,R / R,I / R,M加（溢出安全终止）/ 减 / 比较（不写回）zf cf sf
and / or / xorR,R / R,I按位逻辑zf sf
shl / shrR,R / R,I移位（移位量按 archBits 取模）zf sf
jmpI / R / M无条件跳转—
je / jne / jb / jaeIzf=1 / zf=0 / cf=1（无符号低于）/ cf=0 跳转—
callI / R / interface压返回地址跳转；接口形态由引擎管理调用；深度 ≤64—
ret—弹出栈顶为新执行位置（动态目标；非法位置 → invalid_rip）—
syscallI0x00–0xFF 内置 exit(I)；≥0x0100 走作者接口；无宿主副作用—

操作数类别：R = 寄存器（一般 ∪ FLAG）；I = 立即数（无符号，archBits 域，hex）； M = 内存（基址寄存器 + 有符号位移）；interface = {kind:"interface", interfaceId}。每指令 ≤4 操作数。 IR 助记符双形态：基线小写枚举 ∪ 大写自定义助记符（须已声明、零操作数）。

R4 · 谓词 / 微算子 / 效果原语参数表

7 谓词参数语义

ret_target_equalsaddressHexret 弹出目标判定
stack_canary_intact—守护完好（未启用时恒真）
virtual_file_readfileId ∈ secrets.virtualFiles密档已被读
6 微算子（customInstructions.semantics）参数语义
load_immdst（一般名）、valueHex装载立即数
mov_regdst、src寄存器传送
load_mem / store_memdst / (baseRegister、displacementHex 有符号)、src内存读 / 写
set_flagflagRegister（FLAG 名）、valueHex唯一 FLAG 写入算子
bit_maskdst、src、maskHex、logic ∈ and|or|xor位掩蔽
5 效果原语（interfaces.effects）参数语义
exit—程序终止
grant_virtual_filefileId授予虚拟文件能力

set_flagflagRegister、valueHex置 FLAG 寄存器
noop—占位
