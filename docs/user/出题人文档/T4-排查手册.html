4.1 装载红灯：症状 → 规则 → 修法

症状规则修法

缺 RSP/RBP/RIPXS-REG-COREvmProfile.registers 补齐
FLAG 值出现在公开投影I3-VISIBLE-REG / XS-REG-FLAGFLAG 名不进 registers/visibleRegisters

4.2 裁决回归红灯：五元组逐槽排查

裁决闭环断言五个事实。哪个槽位红了，按表排查（先实跑观察实际行为，再钉语义正确的预期值）：

槽位常见原因处置
① publicStatus 不符exit(1) 不会置 failed（只停机，状态保持 running）；leave 在 ret 前预校验返回槽（crash 早于 ret）；判胜条件被 E1 即时求值提前触发对照 E1 / B3 的语义锚点；预期值按实跑语义钉，不为绿改预期
② 首动作 rejected 形态写隐藏/未映射地址 → 执行前拒绝（revision 不前进）；写 rx → 已执行教学失败（不是 rejected）分清"拒绝（未执行）"与"教学失败（已执行）"
③ 末动作错误码错误码选出了枚举（如 invalid_action/memory_fault 不是公开错误码）对照 R6 的 16 错误码表
④ verdict / replayKind 不符重放与在线记录不一致（replay_mismatch）→ 检查是否引入不确定性（时间/未声明随机）；verdict 方向 → 对照 E4 合成规则先修确定性，再钉预期
⑤ hiddenTests 不符success 方向探针不过 = 判题声明与参考解实际行为不一致检查 successCondition 与参考解动作是否真能相遇（E1）
