几条贯穿全文档的底线（先立在此处）

  • 公开 = 你主动下发的：选手浏览器里没有的东西（flag、隐藏区域、窗口外内存）结构上不存在，不存在"被找到"；
  • 题目逻辑没有代码位：全部表达能力 = 20 条指令 + 7 个谓词 + 1 种状态机写法 + 声明式自定义面；注入脚本在语法上不存在；
  • 成绩是重放出来的：verifier 复用同一引擎重放操作日志 + 跑隐藏测试；交互界面上的 won/failed 只是即时反馈；
  • 私有内容永不入 git：语料是 TS 代码，进程内构造双包，git 里只有"生成它们的代码"。
约束数字与枚举一律摘自冻结契约原文（packages/challenge-schema/schema/*.schema.json、 docs/contracts/最小DSL范围.md 等）；本文档为使用文档，与契约/规约冲突时以后者为准。 快速速览版姊妹篇：〈出题人指南〉；界面操作参考：〈界面帮助手册〉。
