## 二、UI 重设计

> **2026-09-18 取代注(前端改版;决议 D-API-153)**:**2.2「工作区:Niri 式固定窗口交互」已被「页面级整页布局」改版取代** —— 工作区**占据整个页面**;页面**左右两分**(**右半侧 = 固定 payload 搭建窗口**;**左半侧 = 视图管理窗口**:在上下两半显示视图、纵向堆叠、上下滚动、滚动带丝滑动画);**无边框紧密贴合**(无间隙 / 无描边 / 无分隔条);**视图类型名写在视图内左上角**(无独立标题栏);列表按钮(展开 / 收起 + 勾选控制左半侧显示哪些视图 + 拖拽排序);`Ctrl + ↑ / ↓` 切换视图窗口。⇒ 列条带模型全部(列间水平滚动、列内二叉分割、**P0 / P1 / P2** 预设与阈值表、列宽五档、列间与窗间分隔条、三类拖拽落点、重置布局、焦点列相机)**废止**。
> **2.1「终端风格设计语言」方向保留但收敛为唯一主题** —— 主题只保留终端一种,`light` / `dark` **退役**(`EMBED_THEMES` 属**冻结契约面** ⇒ 须**先走契约变更流程**)。
> **可读性纪律不得误读**:窗高下限(D-API-152 的 `MIN_ROW_HEIGHT_PX` = 266px)与列高下限的废止**不等于放松可读性** —— 「压缩以适配」这一机制**整条移除**,改由「**左半侧纵向滚动 + 每个视图位有确定高度**」满足;**判据 = 不得出现「视图被压到装不下一行字节」**(历史反例:2026-09-17 取证 4 窗列每窗 146px、面板 chrome 实测 182.1px)。
> **权威文本** = `docs/develop/前端的交互和开发设计.md`「工作区组件」一节 + 其文末 **2026-09-18 增补**;**本改版未落地** —— 磁盘实现仍是本节 2.2 所描述的 Niri 式列条带 ⇒ 现状核对 / E2E / 用户文档仍**以磁盘实现为准**。遗留承接 = `docs/phases/中期遗留清单.md` §十一 **#38**(与评审 §六 #38 双射)。**本节 2.1 / 2.2 / 2.3 原文不删除**(历史记录,勿按 2.2 继续实现)。

### 2.1 终端风格设计语言(黑客氛围)

定位:黑客氛围靠**一致性 + 克制**达成,不靠堆效果;学习可读性优先级高于氛围。现行主题机制(`data-sm-theme` 锚 + CSS 自定义属性穿透 shadow DOM,WP-53)整体沿用,变量面从"8 个功能对比度变量"扩展为完整设计 token 集——**显式修订** `theme-tokens.ts` 头注释"视觉风格零重设计,只做功能对比度最小变量面"的既有边界(登记为本计划的边界变更)。

- **Token 集**(目标 ~16 个,light / dark 维持,新增 `terminal` 预设集):
  - 背景三层:`--sm-bg-base`(近黑底,非纯黑)`--sm-bg-panel`(面板)`--sm-bg-inset`(内嵌区);
  - 前景:`--sm-fg`(磷光绿)`--sm-fg-dim`(暗绿注释层);
  - 语义色:`--sm-accent`(磷光绿,地址/链接/跳转)、`--sm-warn`(琥珀,断点/暂停/警告)、`--sm-danger`(现有变量并入)、`--sm-selection`、`--sm-focus-ring`;
  - 字体:`--sm-font-mono`;效果:`--sm-scanline-opacity`、`--sm-caret-blink`。
- **字体栈**:`ui-monospace, "Cascadia Code", "JetBrains Mono", Consolas, "Noto Sans Mono CJK SC", monospace`;全组件统一;中英混排宽度由字体栈兜底;字号下限 13px。
- **色板纪律**:磷光绿前景 + 近黑背景;琥珀 = 断点/暂停,红 = 错误/危险,青绿 = 可点击地址;**全部色值以 axe color-contrast 真机门禁为唯一口径**(沿用 WP-55 先例);禁大面积 glow / text-shadow。
- **效果面**(全部尊重 `prefers-reduced-motion` 与"动画只用 transform/opacity"既有纪律):扫描线 overlay(`repeating-linear-gradient`,opacity ≤ 0.06,`aria-hidden` 纯装饰)、光标闪烁(steps 动画)、终端式窗口标题栏(1px 框线 + 角标)。
- **契约注意点**:嵌入协议外观主题载荷为冻结面时,`terminal` 以 `data-sm-theme` 扩展值承载、宿主侧 appearance 映射为 dark + 变量覆盖,**不动冻结 V 规则**;若需协议面承载,走 additive 演进(决策点 D-MP-2)。
- **性能护栏**:零新增运行时依赖(纯 CSS token,零 JS 主题解析);主 chunk(≈1.2MB)拆分列为可选增量,不与本计划绑定。

### 2.2 工作区:Niri 式固定窗口交互(全显示、不关闭、可调大小)

现状与问题:默认零预开、空态引导;标签可开可关、同类型可多开;列内 flex 均分——**窗口既小又不可调整大小**。按主控定案重新设计:**窗口全部常驻、不提供关闭,管理动作只有位置与大小调整;交互形态仿照 Niri(列式滚动平铺)**。

**模型(固定窗口集)**:

1. 工作区注册表登记的**全部窗口类型常驻、各恰好一个实例**(栈视图、自由视图、指令视图、寄存器视图、Payload 搭建、调用栈、结构视图、时间线、checkpoint、内存 diff 等,以 tab-registry 登记集合为准);教学面板(提示阶梯 + 错误解释器)维持底部常驻面板形态。
2. **移除标签页生命周期**:无关闭按钮、无"打开标签"菜单;窗口不再有开/关状态,只有"视口内 / 暂离(条带滚出视野)"。解题↔调试模式切换只换绑数据源,窗口集合与布局不动。
3. 窗口管理动作收敛为三类:**移动位置**(跨列 / 列内重排)、**调整大小**(列宽 / 窗高)、**聚焦导航**。

**Niri 交互设计**:

1. **列式滚动条带**:窗口组织为垂直列,列组成水平条带;"相机"跟随焦点列——焦点列居中显示,相邻列在两侧探出(暗示可继续滚动);条带平滑滚动(scrollToColumn 基建已有)。
2. **列宽可调**:相邻列间拖拽分隔条连续调整;另提供预设档(1/4、1/3、1/2、2/3、全宽)快捷切换——直接解决"窗口太小"。列宽设最小值护栏(十六进制行不折行的最小可读宽度)。
3. **窗高可调**:同列多窗口时,窗口间拖拽分隔条调整高度比例;单窗列自动占满列高。行渲染沿用虚拟列表,拖拽期间不整列表重排。
4. **拖拽重排**(升级既有拖拽基建为 Niri 落点语义):拖窗口标题栏到另一列 = 跨列移动;落到某窗口上/下半部 = 插到其上/下方(同列堆叠);落到列间空隙 = 新建列位。全程无浮动、无重叠、无最小化。
5. **聚焦导航**:点击窗口即聚焦;工作区菜单"窗口"项 = 滚动条带聚焦对应窗口(替代原"打开标签");键盘快捷键(左右切焦点列、上下切焦点窗口)登记为可选增量,不承诺。
6. **默认布局预设 P0**(宽屏):列 1 = 栈视图 + 寄存器视图;列 2 = 指令视图 + 自由视图;列 3 = Payload 搭建;列 4 = 调用栈 + 结构视图;列 5 = 时间线 + checkpoint + 内存 diff。提供"重置布局"一键回到 P0。解题档指令视图以"单条当前指令 + 调试档解锁引导"形态参与(不改 D3 投影面)。
7. **响应式降级**:中宽 = 自动减列(预设合并);窄条(iframe 竖条)= 单列纵向 + 窗口切换条聚焦。
8. **性能护栏**:全窗口常驻 = DOM 常驻,视口外窗口以 `content-visibility` / 交叉观察降级渲染;行级虚拟列表(sm-window-list)维持;布局状态随会话内存保持,**布局持久化为可选增量**(与 IndexedDB 持久化一并评估,不入本计划义务);主题与布局改造零新增运行时依赖。

## 六、红线与不变量(执行期逐 WP 自查)

- 安全红线(计划书十六章)逐条维持:**黑客氛围仅存在于视觉与文案层**,不新增任何攻击能力、不绕过 D3 投影窗口边界与 D5"非可执行 IR"边界;
- 12 动作冻结面不扩;断点联动只在 ADR-DC1 调试通道语义内;解题档"输入地址跳转"维持窗口形态与"窗口外反馈";
- 契约变更(嵌入协议值域、公开描述包 interface、成绩接口)一律先契约后实现,golden fixture TS/Rust 双语言同步;
- 覆盖率 ≥80% 门禁维持;新 UI 逻辑 TDD、行为命名;
- 动画只用 transform/opacity;`prefers-reduced-motion` 必须被尊重;屏幕阅读器信息不得只存在于视觉效果中;终端主题色值以 axe 真机门禁为唯一口径。
