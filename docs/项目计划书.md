# StackMaster 项目计划书

## 产品定位

一个可嵌入、可回放、可解释的 Pwn 概念实验室，而不是浏览器中的完整 Linux 或 x86 模拟器。

由于 AI 的冲击，在 CTF 新生赛中放一些经典的题目的必要性已经丧失，且难以让新生获得学习的正向反馈，所以我们需要一些新的手段去更好的反映、提升新生的水平与兴趣。

因此，该项目将通过一个将内存可视化展现出来的 vm ，让新生通过指定的操作方式直接操作内存来解决 vm 中的谜题来学习 pwn 的基础知识。同时为了方便各靶场引入该项目，项目将以 Web 插件的形式去实现。

同时为了具备更好的可拓展性，项目将允许出题人更加方便地去修改虚拟指令集、方法、寄存器和内存布局，这意味着项目将具备一定程度的框架属性。
